## Summary

Imported a 5-terminal pinout for the DBV SOT-23-5 variant only (IN, GND, EN, NC, OUT per Table 4-1) with two peripherals (power: input/output/ground; enable: enable) and 7 design-rule warnings (input/output capacitor requirement, EN thresholds and no internal pull, EN-above-VIN frequency limit, reverse-current limit at OUT, no thermal pad on DBV, NC pin unused, enable needed for regulation). Built the package and footprint from the DBV0005A mechanical drawing and its example board layout using the built-in tabbed starter row "SOT-23-5": body 2.9 x 1.6 mm, lead span 2.8 mm, pitch 0.95 mm, 5 lands 0.6 x 1.1 mm at 2.6 mm row-centre span, generated 3D model (no built-in part file covers a SOT-23-5), text-only can marking "1FKF" from the package addendum. Everything checks without blocking findings; the 5 imported terminals are still unreviewed, which is expected. Row positions and body height were derived arithmetically from the drawing's min/max ranges — see the confidence flags and open questions below.

## Open questions

- [ ] The 3.3 V output is inferred from the ordering code "33" in Table 8-1; Table 4-1 itself is voltage-agnostic. Confirm the option is what the buyer intends (the pinout/package are identical for all voltages).
- [ ] Body height, body width, span and lead width were taken as the mid value of each min/max range because the drawing prints no nominal — confirm against IPC-7351 or the customer's panel if a tighter fit matters.
- [ ] lead_thickness (0.15 mm) and foot_length (0.4 mm) came from the built-in starter row, not read unambiguously from the section view of DBV0005A; verify the lead profile before relying on the courtyard/silkscreen extents.
- [ ] The land pattern on page 35 is an "example" whose values are parenthetical reference dimensions, and note 6 says IPC-7351 may have alternate designs — confirm the 0.6 x 1.1 mm lands and 2.6 mm row span are acceptable for the intended assembly.
- [ ] Solder-mask style: the drawing prefers non-solder-mask-defined (0.07 mm max around the land); the footprint uses the library default 0.05 mm mask expansion — set it to the fab's rule if this matters.
- [ ] The datasheet is inconsistent about the discharge resistor: 120 Ω in Section 6.3.1/6.3.2 versus "RPULLDOWN 95 Ω typ, VIN = 3.3 V (P version only)" in Section 5.5 — both were quoted in the rules; a person should decide which number to publish.
- [ ] Pin 4 (NC) is kept as a footprint land per the datasheet land pattern (5 lands). Confirm the design should keep it as a floating/keep-out pad rather than omit it.
- [ ] All 5 imported terminals are still unreviewed (pinout.unreviewed); they are not flagged uncertain, but a person must review them before publishing.
