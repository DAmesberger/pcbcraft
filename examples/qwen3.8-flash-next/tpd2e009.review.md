## Summary

Built the TPD2E009 as a 3-terminal passive ESD-protection part, DBZ (SOT-23) package only, per the request. Pinout: pin 1 D+, pin 2 D- (both 'ESD port', one shared TVS clamp to GND), pin 3 GND, from the page-3 Pin Functions table; one peripheral 'ESD' with roles D+ and D-, no GPIO/mux (the part has none - no IO MUX, strapping, debug or power pins exist, so no flash/JTAG/USB rules apply). Three rules were added instead: GND must be assigned (require), a warn when only one of the two ESD ports is used (they share one TVS diode, page 9), and a warn that the passive clamp has no supply and its ports must stay within 0-5.5 V. Preview was clean (no refusal, no rule failure; the only blocking findings before the footprint existed were package.envelope and binding.footprint_count, both resolved by the package build). Package/footprint from the DBZ0003A outline (page 17) and its example land pattern (page 18) using the built-in SOT-23-3 tabbed starter row, values corrected: body 2.92 x 1.3 x 0.95 mm, tip-to-tip span 2.4 mm, lead width 0.4, thickness 0.12, foot length 0.4, standoff 0.05, pitch 0.95 (starter/generator convention: the built footprint places pads 1 and 2 1.9 mm apart, which equals the drawing's boxed 1.9 dimension, and the rows 2.1 mm apart = the land pattern's (2.1)); lands 0.6 wide x 1.3 long taken from the recommended pattern (3X (0.6) / 3X (1.3) / 2X (0.95) / (2.1)) rather than the starter's estimates. Terminals matched by number (3 kept, 0 renumbered). Generated 3D model kept (no built-in SolidCraft part file covers a bare SOT-23-3; esp32-s31-wroom-3 is a module and was not used). Can marking set to text 'NFLR' (laser etch); no vendor logo, no polarity mark (the drawing shows a moulded pin-1 index area, which the footprint's pin-1 dot and polarity pad already represent). Everything is unreviewed (3 imported terminals) and not published. Check first: the derived lead foot length/standoff and body height (see open questions), and that only the DBZ variant was requested - the DRT (1.0 x 0.8 mm) option was deliberately not built.

## Open questions

- [ ] Only the DBZ (SOT-23-3, 2.92 x 1.3 mm) variant was built as requested; the DRT (1.0 x 0.8 mm) option on pages 1 and 12 is not in this part.
- [ ] Body height, foot length and standoff are not printed as single values on DBZ00003A (only ranges and 1.12 mm max overall height): body_height 0.95, foot_length 0.4 and standoff 0.05 were derived - confirm against the assembly drawing or IPC-7351 before publish.
- [ ] The page-17 drawing's '2X 0 -8 deg' / '0.10 TYP 0.01' pair was read as the seating-plane/coplanarity condition; confirm it is not a standoff call-out that should replace 0.05 mm.
- [ ] Note 4 on page 17: 'Support pin may differ or may not be present' (the (0.15) dimension). It is not in the 3-pin table, so no terminal was created - confirm no extra land is needed on the host footprint.
- [ ] The land pattern is an 'example' and IPC-7351 permits alternates (page 18 note 5); confirm the chosen 0.6 x 1.3 mm lands and 0.05 mm mask expansion against your fab rules (TI prefers non-mask-defined, 0.07 max under metal).
- [ ] Marking: the addendum lists 'NFLO, NFLR' for DBZR parts; the can/silkscreen text was set to NFLR - confirm which one ships.
- [ ] The 3 imported terminals (D+, D-, GND) are unreviewed; they must be cleared by a person before publishing.
- [ ] The part has no GPIO, mux table, strapping, debug, USB or memory pins, so no such rules were written; the ESD clamp itself is documented through the 'ESD' peripheral (roles D+, D-) rather than through any switch-matrix peripheral.
